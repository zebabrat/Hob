# Инструкции для Claude Code в этом репозитории

## Никаких упоминаний Claude/AI в git и деплое

Нигде в этом репозитории не должно быть упоминаний Claude, Anthropic или AI-ассистента:

- **Коммиты**: НЕ добавлять строку `Co-Authored-By: Claude ...` или любой другой footer/trailer с упоминанием Claude/Anthropic в сообщение коммита. Автор коммита — только пользователь (текущий git user.name/user.email), без соавторов от ИИ.
- **PR**: в описании и заголовке PR не упоминать Claude, Claude Code, Anthropic, "Generated with Claude Code" и т.п.
- **Деплой**: в названиях деплоев, комментариях к деплою, env-переменных, комментариях в коде — не упоминать Claude/AI как автора или источник изменений.

Это правило действует всегда, автоматически, без необходимости напоминать о нём в каждом чате.
